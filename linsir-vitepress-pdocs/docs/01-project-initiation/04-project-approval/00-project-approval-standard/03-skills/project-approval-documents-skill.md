# Skill: project-approval-documents-process

## 描述
指导项目审批阶段审批文档（项目批准通知书和项目授权书）的编制、审核和签署流程。

## 调用条件
当用户需要创建项目审批文档、编制项目批准通知书、编制项目授权书、或进行项目审批文档审核时调用此Skill。

## 流程步骤

### 步骤1：编制项目批准通知书
- **步骤编号**：PA-DOC-001
- **执行角色**：项目管理办公室
- **预计工时**：0.5天
- **输入**：高层审批表、项目章程、立项申请报告、各部门审查意见
- **编制内容**：
  1. 批准决定（项目信息、批准结果、投资预算、团队授权）
  2. 项目目标确认（业务、技术、管理、质量目标）
  3. 管理要求（进度、质量、风险、变更管理）
  4. 资源保障（人力、基础设施）
- **质量检查点**：
  - 项目基本信息准确无误
  - 预算金额与财务审查一致
  - 里程碑时间与项目计划一致
  - 团队配置符合项目需求
- **输出**：项目批准通知书（初稿）

### 步骤2：审核项目批准通知书
- **步骤编号**：PA-DOC-002
- **执行角色**：项目发起人、IT总监、财务总监、总经理
- **预计工时**：0.5天
- **审核流程**：
  1. 项目发起人审核（目标、范围、预算、里程碑）
  2. IT总监审核（技术方案、资源、风险）
  3. 财务总监审核（预算、资金、分类）
  4. 总经理审核（整体价值、战略契合）
- **审核结果**：通过进入步骤3，不通过返回步骤1修改
- **输出**：审核意见记录、批准通知书（审核稿）

### 步骤3：批准签字
- **步骤编号**：PA-DOC-003
- **执行角色**：各级审批人
- **预计工时**：0.5天
- **签字顺序**：编制人 → 审核人 → 项目发起人 → IT总监 → 财务总监 → 总经理
- **签字要求**：每级签字人需签署意见
- **文档归档**：原件存档、扫描件分发、更新文档清单
- **输出**：项目批准通知书（正式版）

### 步骤4：编制项目授权书
- **步骤编号**：PA-DOC-004
- **执行角色**：项目管理办公室
- **预计工时**：0.5天
- **输入**：项目批准通知书、项目章程、项目经理信息
- **编制内容**：
  1. 授权声明（依据、项目信息、有效期）
  2. 项目发起人授权（职责、权限明细）
  3. 项目经理任命（职责、权限：人员、财务、技术、日常）
  4. 核心团队成员任命（技术负责人、业务负责人、PM专员）
  5. 授权限制（上报事项、禁止事项、有效期）
  6. 责任与义务
- **质量检查点**：
  - 授权依据引用正确
  - 权限范围明确清晰
  - 责任界定清楚
  - 限制条件合理
- **输出**：项目授权书（初稿）

### 步骤5：审核项目授权书
- **步骤编号**：PA-DOC-005
- **执行角色**：项目发起人、人力资源部、法务部
- **预计工时**：0.5天
- **审核流程**：
  1. 项目发起人审核（授权范围、边界、责任）
  2. 人力资源部审核（任命合规、绩效、汇报关系）
  3. 法务部审核（法律合规性，如需要）
- **输出**：审核意见记录、项目授权书（审核稿）

### 步骤6：授权签署
- **步骤编号**：PA-DOC-006
- **执行角色**：项目发起人、项目经理、见证人
- **预计工时**：0.5天
- **签署顺序**：项目发起人 → 项目经理 → 见证人（HR、IT总监、PMO）
- **签署要求**：
  - 项目发起人：正式授权，提供支持
  - 项目经理：接受授权，承诺履职
  - 见证人：见证签署过程
- **文档归档**：三方各执一份、扫描件存档、更新文档清单
- **输出**：项目授权书（正式版）

## 输入条件
- 高层审批表（SYS-PI-PA-010）已批准
- 项目章程（SYS-PI-PC-000）已完成
- 立项申请报告（SYS-PI-PA-002）已审批
- 各部门审查意见已汇总

## 质量标准

### 文档质量标准
- 完整性：所有必填项已填写
- 准确性：数据与源文档一致
- 规范性：格式符合模板要求
- 一致性：各文档间信息一致

### 审批质量标准
- 审核完整性：所有审核环节已完成
- 签字完整性：所有签字栏已签署
- 意见明确性：审核意见清晰明确

## 关键控制点
- CP1：批准通知书内容完整性（质量检查清单）
- CP2：预算金额准确性（与财务审查核对）
- CP3：授权范围合理性（项目发起人确认）
- CP4：签字完整性（签字栏检查）

## 异常处理

### 审核不通过
- 记录审核意见
- 返回修改
- 重新提交审核

### 签字人不在
- 授权他人代签或延期签署
- 需书面说明

### 授权范围争议
- 召开协调会
- 明确权限边界
- 书面确认

## 角色与职责
| 角色 | 职责 | 参与步骤 |
|-----|------|---------|
| 项目管理办公室 | 文档编制、流程协调 | 步骤1、4 |
| 项目发起人 | 审核、批准、授权 | 步骤2、3、5、6 |
| IT总监 | 技术审核、见证签署 | 步骤2、3、6 |
| 财务总监 | 财务审核、批准 | 步骤2、3 |
| 总经理 | 最终批准 | 步骤3 |
| 人力资源部 | 人员任命审核、见证 | 步骤5、6 |
| 项目经理 | 接受授权 | 步骤6 |

## 流程度量

### 效率指标
- 编制周期：≤1天
- 审核周期：≤2天
- 签署周期：≤1天
- 总周期：≤4天

### 质量指标
- 一次通过率：≥80%
- 返工率：≤20%
- 文档完整率：100%
