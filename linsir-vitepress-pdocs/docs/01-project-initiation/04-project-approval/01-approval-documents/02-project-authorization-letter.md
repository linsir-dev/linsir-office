## 五、授权限制

### 5.1 权限边界

**需上报审批的事项**：

| 事项类型 | 上报条件 | 审批人 |
|---------|---------|--------|
| 范围变更 | 任何范围变更 | 项目发起人 |
| 预算超支 | 超过批准预算10% | 项目发起人+财务总监 |
| 进度延期 | 关键里程碑延期超过1周 | 项目发起人 |
| 人员变更 | 核心团队成员变更 | 项目发起人 |
| 重大风险 | 高风险事件发生 | 项目发起人 |
| 合同变更 | 供应商合同重大变更 | 项目发起人+法务 |

**禁止事项**：
- 未经批准超出项目范围承诺交付
- 未经批准签订对外合同
- 未经批准调整项目预算
- 未经批准变更项目目标

### 5.2 授权有效期

- **生效日期**：2026年3月13日
- **有效期**：至项目验收完成或项目终止
- **授权撤销**：项目发起人可随时撤销或调整授权
