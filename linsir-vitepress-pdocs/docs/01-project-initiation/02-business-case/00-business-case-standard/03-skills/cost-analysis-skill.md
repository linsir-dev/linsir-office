# 成本分析流程 Skill

## 概述

本Skill指导完成商业论证阶段的成本分析工作，包括开发成本、运维成本和其他相关成本的全面估算。

## 适用场景

- 需要进行项目成本分析
- 估算开发、运维和其他相关成本
- 创建成本分析文档
- 审核成本估算的合理性

## 成本分析流程

### 步骤1：开发成本估算

**目标**：估算项目开发阶段的所有成本

**成本类别**：
1. **人力成本**
   - 项目经理：全程参与
   - 开发人员：前端、后端、架构师
   - 测试人员：功能测试、性能测试
   - 其他角色：产品经理、UI设计师、DevOps

2. **硬件成本**
   - 开发环境硬件：笔记本、显示器、外设
   - 服务器硬件：开发服务器、测试服务器

3. **软件成本**
   - 开发工具许可：IDE、设计工具
   - 测试工具许可：测试管理工具
   - 其他软件：项目管理工具、协作工具

4. **外包成本**
   - UI设计外包
   - 安全渗透测试
   - 性能测试服务
   - 技术咨询

**风险预留**：建议增加15%风险储备金

**输出文档**：`01-cost-development.md`

**审核**：项目经理审核

---

### 步骤2：运维成本估算

**目标**：估算系统上线后3年的运维成本

**成本类别**：
1. **基础设施成本**
   - 云服务器：生产环境、预发布环境
   - 存储成本：数据库、文件存储、备份
   - 网络与带宽：公网带宽、CDN、安全防护

2. **运维人力成本**
   - 运维经理
   - 运维工程师（高级/中级）
   - 数据库管理员（DBA）
   - 安全工程师
   - 技术支持工程师

3. **软件维护成本**
   - 软件许可续费：数据库、监控工具
   - 技术支持服务：云服务商、原厂支持

**风险预留**：建议增加10%风险储备金

**输出文档**：`02-cost-operation.md`

**审核**：运维经理、财务负责人审核

---

### 步骤3：其他成本估算

**目标**：估算培训、数据迁移和项目管理成本

**成本类别**：
1. **培训成本**
   - 用户培训：系统管理员、普通用户、管理层
   - 运维培训：运维工程师、DBA、安全工程师

2. **数据迁移成本**
   - 数据迁移工具
   - 数据清洗服务
   - 数据验证服务
   - 临时存储资源

3. **项目管理成本**
   - 项目管理工具
   - 会议场地和餐饮
   - 项目文档制作
   - 项目审计

**风险预留**：建议10-20%风险预留

**输出文档**：`03-cost-other.md`

**审核**：项目经理、财务负责人审核

---

### 步骤4：成本汇总与审核

**目标**：汇总所有成本并进行最终审核

**活动**：
1. 成本分类汇总
   - 开发成本
   - 运维成本（3年）
   - 其他成本

2. 风险预留计算
   - 开发成本：15%
   - 运维成本：10%
   - 其他成本：10-20%

3. 成本优化建议
   - 基础设施优化
   - 人力成本优化
   - 其他成本优化

**审核**：财务负责人审核

---

## 审核流程

### 审核节点

| 步骤 | 审核人 | 审核重点 |
|-----|--------|---------|
| 步骤1 | 项目经理 | 开发成本完整性、准确性 |
| 步骤2 | 运维经理、财务负责人 | 运维资源配置、成本准确性 |
| 步骤3 | 项目经理、财务负责人 | 其他成本周全性、风险预留 |
| 步骤4 | 财务负责人 | 成本汇总准确性 |

### 审核标准

- 所有成本数据必须有依据和来源
- 成本估算应基于市场行情和历史数据
- 风险预留比例应符合项目特点
- 审核意见和签字必须完整

---

## 成本汇总

### 成本构成

```
项目总成本 = 开发成本 + 运维成本（3年） + 其他成本
```

### 典型成本分布

- 开发成本：约20-25%
- 运维成本（3年）：约70-75%
- 其他成本：约4-5%

## 注意事项

1. **成本估算方法**：采用自下而上估算，从具体资源需求汇总
2. **数据来源**：参考市场行情、历史项目数据、供应商报价
3. **风险考虑**：充分考虑人员流动、需求变更、技术难点等风险
4. **审核要求**：必须经过项目经理和财务负责人双重审核
5. **文档规范**：使用统一的文档模板和编号体系
