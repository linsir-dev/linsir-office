## 2. 授权范围

### 2.1 项目管理权限

| 权限类别 | 授权内容 | 授权级别 |
|---------|---------|---------|
| **预算管理** | 项目预算内的资金支配 | 全权 |
| **人员管理** | 项目团队成员的调配和管理 | 全权 |
| **进度管理** | 项目进度计划的制定和调整 | 全权 |
| **范围管理** | 项目范围的定义和变更（预算内） | 全权 |
| **质量管理** | 项目质量标准的制定和执行 | 全权 |
| **风险管理** | 项目风险的识别和应对 | 全权 |
| **沟通管理** | 项目沟通的组织和协调 | 全权 |

### 2.2 决策权限

| 决策事项 | 决策权限 | 备注 |
|---------|---------|------|
| 预算内支出（<5万元） | 项目经理决策 | 无需审批 |
| 预算内支出（5-10万元） | 项目经理提议，发起人审批 | 邮件确认 |
| 预算外支出 | 需指导委员会审批 | 正式会议 |
| 人员调配（项目内） | 项目经理决策 | 通知HR |
| 人员调配（跨部门） | 需相关部门负责人同意 | 协商确定 |
| 进度调整（<2周） | 项目经理决策 | 通知相关方 |
| 进度调整（>2周） | 需发起人审批 | 正式申请 |
| 范围变更（ minor） | 项目经理决策 | 记录备案 |
| 范围变更（ major） | 需指导委员会审批 | 变更流程 |

### 2.3 签字权限

| 文件类型 | 签字权限 | 备注 |
|---------|---------|------|
| 项目内部文档 | 项目经理签字 | 技术文档、会议纪要等 |
| 对外商务文件 | 需发起人联签 | 合同、采购单等 |
| 项目交付物 | 项目经理签字 | 测试报告、验收申请等 |
| 项目结项报告 | 需指导委员会签字 | 正式结项 |

## 6. 授权撤销

在以下情况下，项目发起人有权撤销对项目经理的授权：

1. **严重违反公司制度**：如贪污、舞弊等行为
2. **重大失职**：导致项目严重延期或重大损失
3. **能力不足**：无法胜任项目管理工作
4. **主动辞职**：项目经理主动提出不再担任
