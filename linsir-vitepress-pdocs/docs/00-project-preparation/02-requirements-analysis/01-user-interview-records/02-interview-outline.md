# System 系统需求调研 - 访谈提纲

## 一、决策层访谈提纲（CEO/总经理）

### 1. 战略定位
- 请介绍一下公司未来3-5年的数字化战略规划
- System 基础平台在整个数字化战略中扮演什么角色？
- 您认为 System 系统建设对公司的核心价值是什么？

### 2. 目标期望
- 您希望通过 System 系统解决哪些关键业务问题？
- 对 System 系统的建设目标有什么具体期望？
- 您认为项目成功的标准是什么？
- 项目成功的关键指标有哪些？

### 3. 投资回报
- 对 System 系统建设的投资预算大概是多少？
- 期望多长时间能够看到投资回报？
- 如何量化 System 系统带来的价值？

### 4. 合规与风险
- 是否有等保、ISO27001等合规要求？
- 对数据安全和隐私保护有什么特殊要求？
- 您认为项目最大的风险是什么？

### 5. 优先级与里程碑
- 哪些功能是必须优先实现的？
- 对项目上线时间有什么要求？
- 是否可以分阶段交付？

---

## 二、管理层访谈提纲（IT总监/行政经理）

### 1. 现有系统现状
- 公司目前有哪些业务系统？各自使用什么技术栈？
- 现有系统的用户管理和权限控制是如何实现的？
- 目前各系统之间的数据是如何同步的？

### 2. 技术架构
- 对 System 系统的技术架构有什么要求？
- 需要支持哪些集成方式（API、SSO、LDAP等）？
- 对系统的扩展性和性能有什么要求？

### 3. 用户与权限管理
- 公司目前的组织架构是怎样的？有多少部门？
- 预计 System 系统需要管理多少用户？
- 用户角色和权限如何划分？

### 4. 安全与合规
- 对密码策略有什么具体要求？
- 是否需要支持多因素认证？
- 操作日志需要保留多长时间？

### 5. 运维与支持
- 系统上线后由谁负责运维？
- 对系统的可用性有什么要求（SLA）？
- 是否需要提供培训和技术支持？

---

## 三、执行层访谈提纲（运维主管/HR专员/开发工程师）

### 1. 日常工作流程
- 请描述一下您目前的日常工作流程
- 在工作中使用哪些系统？频率如何？
- 目前工作中最大的痛点是什么？

### 2. 用户管理场景
- 新员工入职时，账号开通的流程是怎样的？
- 员工离职时，账号处理的流程是怎样的？
- 员工转岗时，权限变更的流程是怎样的？

### 3. 权限管理场景
- 目前是如何分配和管理用户权限的？
- 权限申请和审批的流程是怎样的？
- 是否遇到过权限分配错误或遗漏的情况？

### 4. 组织架构管理
- 公司的组织架构多久变更一次？
- 部门合并或拆分时，系统如何处理？
- 岗位变动时，数据权限如何调整？

### 5. 具体功能需求
- 您希望 System 系统提供哪些功能？
- 对系统的易用性有什么期望？
- 需要哪些报表和统计功能？

### 6. 集成与对接
- 您使用的业务系统需要与 System 系统对接吗？
- 需要哪些数据同步或共享？
- 对接口的实时性有什么要求？

## 四、通用问题清单

### 4.1 现状了解
1. 您目前在工作中使用哪些系统？
2. 这些系统的用户管理和权限控制是如何实现的？
3. 您在登录不同系统时遇到过什么问题？
4. 目前权限申请和变更的流程是怎样的？
5. 您是否遇到过权限不足或权限过大的情况？

### 4.2 痛点挖掘
1. 您在用户管理方面遇到的最大困难是什么？
2. 目前的权限管理存在哪些问题？
3. 组织架构维护方面有什么痛点？
4. 系统管理员的工作负担主要在哪些方面？
5. 普通用户在使用系统时经常遇到什么问题？

### 4.3 需求探索
1. 您希望 System 系统首先解决什么问题？
2. 您认为 System 系统必须具备哪些核心功能？
3. 对系统的操作便捷性有什么期望？
4. 需要哪些自动化功能来减轻工作负担？
5. 对系统的响应速度有什么要求？

### 4.4 期望与建议
1. 您对 System 系统的整体期望是什么？
2. 您认为 System 系统上线后会带来哪些改变？
3. 对系统的界面设计有什么建议？
4. 希望提供哪些培训和支持？
5. 还有其他建议或补充吗？

## 五、访谈技巧提示

### 5.1 开场白
- 感谢对方抽出时间参加访谈
- 说明访谈目的和预计时长
- 强调访谈内容仅用于需求分析，会保密处理
- 征得对方同意后进行录音（如需要）

### 5.2 提问技巧
- 使用开放式问题，避免是非题
- 多使用"为什么"、"能否举例说明"等追问
- 注意观察对方的表情和语气
- 适时总结确认，确保理解正确

### 5.3 记录要点
- 记录关键观点和核心需求
- 记录提到的痛点和问题
- 记录具体的业务场景和案例
- 记录待确认和待跟进的事项

### 5.4 结束语
- 总结访谈要点，确认理解无误
- 说明后续的工作安排
- 感谢对方的配合和支持
- 留下联系方式，方便后续沟通
