## 三、

### 3.1 通用议题（所有对象）

1. 请介绍一下您当前的工作职责和日常工作流程
2. 您目前在工作中遇到的最大痛点是什么？
3. 您对 System 系统有哪些期望和需求？
4. 您认为 System 系统应该优先解决哪些问题？
5. 您希望 System 系统如何改善您的工作效率？

### 3.2 决策层专项议题

1. 公司数字化转型的整体战略是什么？
2. System 系统在数字化战略中的定位和作用？
3. 对 System 系统的投资回报期望是什么？
4. 项目成功的关键指标有哪些？
5. 对项目进度和里程碑的要求？
6. 是否有合规或审计方面的特殊要求？

### 3.3 管理层专项议题

1. 现有的 IT 架构和技术栈是什么？
2. System 系统需要与哪些现有系统集成？
3. 对系统安全和数据保护的要求？
4. 用户规模和增长预期是多少？
5. 对系统性能和可用性的要求？
6. 预算和资源投入的计划？

### 3.4 执行层专项议题

1. 当前用户管理和权限分配的具体流程？
2. 日常运维中遇到的具体问题？
3. 组织架构管理的现状和痛点？
4. 入职离职流程中系统支持的需求？
5. 对系统易用性和操作效率的期望？
6. 需要哪些报表和统计功能？
