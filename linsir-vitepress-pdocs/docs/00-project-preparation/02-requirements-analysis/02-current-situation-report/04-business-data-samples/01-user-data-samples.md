## 五、数据同步需求

### 5.1 实时同步字段

- 员工状态（入职/离职/调动）
- 账号启用/禁用状态

### 5.2 定时同步字段

- 基础信息（姓名、部门、岗位）
- 联系方式（手机、邮箱）
- 组织架构信息

### 5.3 同步频率建议

| 数据类型 | 建议频率 | 优先级 |
|---------|---------|-------|
| 员工状态 | 实时 | P0 |
| 组织架构 | 实时 | P0 |
| 基础信息 | 每小时 | P1 |
| 权限信息 | 每天 | P2 |
