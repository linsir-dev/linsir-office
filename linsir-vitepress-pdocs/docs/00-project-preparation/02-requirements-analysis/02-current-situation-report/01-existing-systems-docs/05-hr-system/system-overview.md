## 四、现有痛点

### 4.1 用户管理痛点
- **入职流程**：需要在 HR 系统创建员工，再在各业务系统分别创建账号
- **离职流程**：需要在各系统分别禁用账号，容易遗漏
- **组织架构变动**：需要在各系统分别调整，工作量大且容易出错
- **信息不一致**：HR 系统与业务系统员工信息不同步

### 4.2 系统使用痛点
- 员工自助服务需要单独登录
- 考勤数据与其他系统无法联动

## 五、集成需求（核心）

### 5.1 高优先级需求
- [ ] **组织架构一处维护**：HR 系统作为源头，同步到所有业务系统
- [ ] **入职自动化**：HR 系统创建员工后，自动在各业务系统创建账号
- [ ] **离职自动化**：HR 系统操作离职后，自动禁用各业务系统账号
- [ ] **信息同步**：员工信息变更自动同步到各系统

### 5.2 中优先级需求
- [ ] 统一用户认证（SSO）
- [ ] 权限自助申请
- [ ] 考勤数据集成
