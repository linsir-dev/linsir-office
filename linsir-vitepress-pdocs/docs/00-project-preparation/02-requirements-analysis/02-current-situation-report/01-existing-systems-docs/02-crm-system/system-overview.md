## 四、现有痛点

### 4.1 用户管理痛点
- 销售人员流动性大，账号管理成本高
- 组织架构变动时权限调整繁琐
- 跨部门协作时权限申请周期长

### 4.2 系统使用痛点
- 销售人员经常外出，需要记住多套密码
- 移动端体验不佳
