# 竞品范围确定

## 一、竞品选择标准

### 1.1 选择维度
- **直接竞品**：提供统一用户权限管理功能的产品
- **间接竞品**：提供部分相关功能的产品
- **参考竞品**：行业内优秀的产品设计参考

### 1.2 选择原则
- 市场占有率高，用户基数大
- 功能完善，有借鉴价值
- 与企业场景匹配度高
- 技术架构可参考
