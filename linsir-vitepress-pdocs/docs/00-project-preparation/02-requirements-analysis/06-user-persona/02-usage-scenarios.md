## 二、系统管理员使用场景

### 场景1：新员工入职账号创建

**场景描述：**
- **触发条件：** 收到HR系统的新员工入职通知
- **参与角色：** 系统管理员
- **使用频率：** 每周2-3次
- **场景价值：** 确保新员工第一天就能使用系统

**使用流程：**
```
1. 登录System平台
   └── 输入用户名密码
   └── 通过二次验证
   
2. 进入用户管理模块
   └── 点击"创建用户"
   
3. 填写用户信息
   └── 用户名（工号）
   └── 姓名
   └── 邮箱
   └── 手机号
   └── 选择部门
   └── 选择岗位
   
4. 分配初始角色
   └── 根据岗位选择默认角色
   
5. 保存并发送通知
   └── 系统自动发送激活邮件
```

**痛点：**
- 需要手动填写大量信息
- 容易遗漏必填字段
- 希望与HR系统自动同步

**期望：**
- 支持批量导入
- 与HR系统对接自动创建
- 模板化快速创建

### 场景2：组织架构调整

**场景描述：**
- **触发条件：** 公司组织架构调整
- **参与角色：** 系统管理员
- **使用频率：** 每季度1-2次
- **场景价值：** 保持组织架构与实际一致

**使用流程：**
```
1. 分析调整方案
   └── 确定部门合并/拆分计划
   
2. 调整部门结构
   └── 创建新部门
   └── 调整部门层级
   └── 合并/删除旧部门
   
3. 批量调整人员
   └── 导出人员清单
   └── 批量修改部门
   └── 验证调整结果
```

---

### 场景3：权限审计

**场景描述：**
- **触发条件：** 季度权限审计
- **参与角色：** 系统管理员
- **使用频率：** 每季度1次
- **场景价值：** 确保权限分配合理安全

**使用流程：**
```
1. 导出权限清单
   └── 按角色导出

2. 分析权限分配
   └── 检查过度授权
   └── 检查权限遗漏
   
3. 调整权限配置
   └── 回收不必要的权限
   └── 补充缺失的权限
```

## 三、部门管理员使用场景

### 场景4：部门人员管理

**场景描述：**
- **触发条件：** 部门内人员变动
- **参与角色：** 部门管理员
- **使用频率：** 每月2-3次
- **场景价值：** 管理部门人员信息

**使用流程：**
```
1. 查看部门人员
   └── 进入组织架构
   └── 选择本部门
   
2. 处理人员变动
   ├── 新员工：确认信息，分配角色
   ├── 调岗：调整岗位和权限
   └── 离职：禁用账号
   
3. 更新部门信息
   └── 修改部门描述
   └── 调整汇报关系
```

---

### 场景5：部门权限分配

**场景描述：**
- **触发条件：** 新员工需要系统权限
- **参与角色：** 部门管理员
- **使用频率：** 每周1-2次
- **场景价值：** 确保员工有合适权限

**使用流程：**
```
1. 评估权限需求
   └── 根据岗位确定所需权限
   
2. 选择用户
   └── 在部门人员列表中选择
   
3. 分配角色
   └── 选择合适的角色
   └── 确认权限范围
   
4. 通知用户
   └── 告知权限已分配
```

## 四、普通用户使用场景

### 场景6：日常工作登录

**场景描述：**
- **触发条件：** 开始工作
- **参与角色：** 普通用户
- **使用频率：** 每天1-2次
- **场景价值：** 访问工作所需系统

**使用流程：**
```
1. 访问System平台
   └── 打开登录页面
   
2. 登录认证
   └── 输入用户名密码
   └── 可能需二次验证
   
3. 进入工作台
   └── 查看待办事项
   └── 访问常用应用
   
4. 访问业务系统
   └── 点击应用图标
   └── 免密进入系统
```

**痛点：**
- 忘记密码
- 登录过程繁琐
- 找不到需要的应用

**期望：**
- 记住登录状态
- 快速访问常用应用
- 清晰的导航

---

### 场景7：个人信息维护

**场景描述：**
- **触发条件：** 个人信息变更
- **参与角色：** 普通用户
- **使用频率：** 每年1-2次
- **场景价值：** 保持信息准确性

**使用流程：**
```
1. 进入个人中心
   └── 点击头像下拉菜单
   
2. 修改信息
   └── 更新联系方式
   └── 上传头像
   
3. 修改密码
   └── 验证旧密码
   └── 设置新密码
   
4. 保存变更
   └── 确认修改成功
```

---

### 场景8：密码重置

**场景描述：**
- **触发条件：** 忘记密码
- **参与角色：** 普通用户
- **使用频率：** 每月数次
- **场景价值：** 自助恢复访问权限

**使用流程：**
```
1. 点击"忘记密码"
   └── 在登录页面
   
2. 验证身份
   └── 输入注册邮箱
   └── 接收验证码
   
3. 重置密码
   └── 输入新密码
   └── 确认新密码
   
4. 完成重置
   └── 使用新密码登录
```

## 五、安全管理员使用场景

### 场景9：安全事件调查

**场景描述：**
- **触发条件：** 发现异常登录或操作
- **参与角色：** 安全管理员
- **使用频率：** 按需
- **场景价值：** 及时发现和处理安全威胁

**使用流程：**
```
1. 发现异常
   └── 监控告警或用户反馈
   
2. 查看日志
   └── 进入审计日志
   └── 筛选相关记录
   
3. 分析行为
   └── 查看登录IP
   └── 分析操作轨迹
   
4. 采取措施
   └── 锁定账号
   └── 通知相关人员
   
5. 生成报告
   └── 导出事件记录
   └── 编写分析报告
```

---

### 场景10：定期安全审计

**场景描述：**
- **触发条件：** 月度/季度审计计划
- **参与角色：** 安全管理员
- **使用频率：** 每月1次
- **场景价值：** 持续监控系统安全

**使用流程：**
```
1. 导出审计数据
   └── 登录日志
   └── 操作日志
   
2. 分析安全指标
   └── 登录失败率
   └── 异常访问模式
   
3. 识别风险
   └── 弱密码账号
   └── 长期未登录账号
   
4. 输出报告
   └── 汇总发现的问题
   └── 提出改进建议
```
