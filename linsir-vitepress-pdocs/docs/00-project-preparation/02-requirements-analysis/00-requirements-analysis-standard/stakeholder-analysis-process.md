# 干系人分析流程规范

## 概述

本文档定义了需求调研与分析阶段中干系人分析的标准流程，用于系统化地识别项目干系人，分析其利益诉求和影响力，制定针对性的沟通策略，确保项目顺利推进。

---

## 分析流程

### 第一步：识别干系人

**目标：** 识别所有内部和外部干系人

**执行步骤：**
1. 审查组织架构
2. 分析业务流程，识别参与者
3. 审查现有文档和访谈记录
4. 识别外部相关方（供应商、合作伙伴、客户）

**输出文档：** `01-stakeholder-identification.md`

---

### 第二步：分析利益诉求和影响力

**目标：** 了解干系人的需求、期望和影响力

**执行步骤：**
1. 分析干系人利益诉求和期望
2. 识别干系人关注点
3. 评估干系人影响力
点和痛4. 评估干系人利益相关度
5. 识别潜在冲突

**输出文档：** `02-stakeholder-analysis.md`

---

### 第三步：建立影响力-利益矩阵

**目标：** 根据影响力和利益相关度对干系人进行分类

**执行步骤：**
1. 将干系人绘制在影响力-利益矩阵上
2. 定义每个象限的管理策略
3. 识别需要特别关注的关键干系人

**影响力-利益矩阵：**
```
                    影响力
              低 ◄─────────────────► 高
              │                      │
         高   │   保持满意       重点管理   │
    利        │                      │
    益   ─────┼──────────────────────┼─────
    相          │                      │
    关   低   │   最少努力       保持知情   │
    度          │                      │
              │                      │
              └──────────────────────┘
```

**管理策略：**
- **重点管理**：高影响力 + 高利益相关
- **保持满意**：低影响力 + 高利益相关
- **保持知情**：高影响力 + 低利益相关
- **最少努力**：低影响力 + 低利益相关

---

### 第四步：制定沟通策略

**目标：** 为不同干系人制定针对性的沟通计划

**执行步骤：**
1. 定义每个干系人的沟通内容
2. 确定沟通频率
3. 选择合适的沟通渠道
4. 指定沟通负责人

---

### 第五步：输出干系人登记册

**目标：** 编制完整的干系人登记册

**执行步骤：**
1. 创建包含所有详情的干系人登记册
2. 记录沟通计划
3. 定义参与策略
4. 跟踪干系人参与情况

**输出文档：** `03-stakeholder-register.md`

## 最佳实践

1. **全面识别**：不要遗漏任何潜在的干系人
2. **客观评估**：客观评估影响力和利益相关度
3. **主动识别**：尽早识别潜在抵触
4. **灵活应对**：干系人立场可能随时间变化
5. **保持沟通**：定期沟通建立信任

---

## 常见陷阱

- ❌ 只关注明显的干系人
- ❌ 忽视非正式影响力者
- ❌ 低估潜在抵触
- ❌ 采用一刀切的沟通方式
- ❌ 不定期更新干系人分析
