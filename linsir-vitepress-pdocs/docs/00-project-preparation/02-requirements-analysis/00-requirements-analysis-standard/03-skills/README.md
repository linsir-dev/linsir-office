## 使用说明

这些Skill文件与 `.trae/skills/` 目录下的Skill文件内容一致，作为备份留存。

Skill文件格式：
```markdown
---
name: "skill-name"
description: "Skill描述"
---

# Skill内容
...
```

## Skill主文件位置

实际生效的Skill文件位于：`.trae/skills/[skill-name]/SKILL.md`
