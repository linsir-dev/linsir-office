## 一、流程概述

### 1.1 流程基本信息

| 属性 | 描述 |
|-----|------|
| 流程名称 | 权限申请流程 |
| 流程编号 | BP-PERM-001 |

## 三、流程步骤详细说明

### 步骤1：提交申请

| 属性 | 描述 |
|-----|------|
| 步骤编号 | S1 |
| 步骤名称 | 提交权限申请 |
| 执行角色 | 申请人 |
| 输入 | 权限需求 |
| 输出 | 权限申请单 |

**申请内容：**
- 申请权限类型（菜单/数据/应用）
- 申请理由
- 申请期限（临时/永久）
- 相关说明

---

### 步骤2：通知审批

| 属性 | 描述 |
|-----|------|
| 步骤编号 | S2 |
| 步骤名称 | 通知审批 |
| 执行角色 | 系统（自动） |
| 输入 | 权限申请单 |
| 输出 | 审批通知 |

**通知方式：**
- 系统消息
- 邮件通知
- 企业微信（可选）

---

### 步骤3：审批申请

| 属性 | 描述 |
|-----|------|
| 步骤编号 | S3 |
| 步骤名称 | 审批申请 |
| 执行角色 | 部门管理员 |
| 输入 | 权限申请单 |
| 输出 | 审批结果 |
| 处理时限 | 2个工作日 |

**审批操作：**
- 通过：同意申请
- 拒绝：说明理由
- 转交：转给上级审批

---

### 步骤4：审批结果通知

| 属性 | 描述 |
|-----|------|
| 步骤编号 | S4 |
| 步骤名称 | 审批结果通知 |
| 执行角色 | 系统（自动） |
| 输入 | 审批结果 |
| 输出 | 结果通知 |

---

### 步骤5-6：权限分配

| 属性 | 描述 |
|-----|------|
| 步骤编号 | S5-S6 |
| 步骤名称 | 执行权限分配 |
| 执行角色 | 系统管理员 |
| 输入 | 审批通过的申请 |
| 输出 | 权限分配结果 |

**操作细节：**
1. 系统管理员收到审批通过通知
2. 登录System平台
3. 为用户分配相应权限
4. 记录权限变更

---

### 步骤7：完成通知

| 属性 | 描述 |
|-----|------|
| 步骤编号 | S7 |
| 步骤名称 | 完成通知 |
| 执行角色 | 系统（自动） |
| 输入 | 权限分配完成 |
| 输出 | 完成通知 |

---

## 四、业务规则

| 规则编号 | 规则描述 |
|---------|---------|
| BR-001 | 权限申请必须说明理由 |
| BR-002 | 部门管理员审批本部门申请 |
| BR-003 | 审批时限为2个工作日 |
| BR-004 | 敏感权限需系统管理员复核 |
| BR-005 | 临时权限到期自动回收 |
