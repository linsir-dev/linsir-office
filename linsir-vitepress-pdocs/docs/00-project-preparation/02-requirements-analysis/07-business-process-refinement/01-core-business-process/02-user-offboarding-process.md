## 一、流程概述

### 1.1 流程基本信息

| 属性 | 描述 |
|-----|------|
| 流程名称 | 用户离职流程 |
| 流程编号 | BP-USER-002 |
| 流程类型 | 核心业务流程 |
| 触发条件 | HR系统发送员工离职通知 |
| 主要参与者 | HR专员、系统管理员、部门管理员 |

- 及时禁用离职员工账号
- 确保数据安全和访问控制
- 保留必要的审计日志
- 完成工作交接

## 三、流程步骤详细说明

### 步骤1：发送离职通知

| 属性 | 描述 |
|-----|------|
| 步骤编号 | S1 |
| 步骤名称 | 发送离职通知 |
| 执行角色 | HR专员 |
| 输入 | 员工离职申请表 |
| 输出 | 离职通知 |
| 触发条件 | 员工离职审批通过 |

**通知内容：**
- 员工姓名、工号
- 所属部门
- 最后工作日
- 离职原因（可选）

---

### 步骤2：工作交接确认

| 属性 | 描述 |
|-----|------|
| 步骤编号 | S2 |
| 步骤名称 | 工作交接确认 |
| 执行角色 | 系统管理员 |
| 输入 | 离职通知 |
| 输出 | 交接任务清单 |

**操作细节：**
1. 系统管理员收到离职通知
2. 联系部门管理员确认工作交接情况
3. 确认需要交接的系统权限和数据
4. 创建交接任务清单

---

### 步骤3：交接完成确认

| 属性 | 描述 |
|-----|------|
| 步骤编号 | S3 |
| 步骤名称 | 交接完成确认 |
| 执行角色 | 部门管理员 |
| 输入 | 交接任务清单 |
| 输出 | 交接完成确认 |

**操作细节：**
1. 部门管理员组织工作交接
2. 转移重要数据和文档
3. 确认交接完成
4. 通知系统管理员

---

### 步骤4：禁用用户账号

| 属性 | 描述 |
|-----|------|
| 步骤编号 | S4 |
| 步骤名称 | 禁用用户账号 |
| 执行角色 | 系统管理员 |
| 输入 | 交接完成确认 |
| 输出 | 账号禁用状态 |
| 处理时间 | 即时 |

**操作细节：**
1. 登录System平台
2. 查找离职员工账号
3. 执行"禁用"操作
4. 记录禁用原因和时间

**业务规则：**
- 禁用操作在最后工作日当天执行
- 禁用后用户无法登录系统
- 用户数据保留，不删除

---

### 步骤5：回收权限

| 属性 | 描述 |
|-----|------|
| 步骤编号 | S5 |
| 步骤名称 | 回收权限 |
| 执行角色 | 系统管理员 |
| 输入 | 已禁用的用户账号 |
| 输出 | 权限回收结果 |

**操作细节：**
1. 系统自动回收所有角色
2. 移除所有应用访问权限
3. 清除数据权限配置
4. 保留权限变更历史

---

### 步骤6：记录审计日志

| 属性 | 描述 |
|-----|------|
| 步骤编号 | S6 |
| 步骤名称 | 记录审计日志 |
| 执行角色 | 系统（自动） |
| 输入 | 离职处理操作 |
| 输出 | 审计日志记录 |

**日志内容：**
- 操作类型：用户离职处理
- 操作用户：系统管理员
- 操作对象：离职员工账号
- 操作时间
- 操作详情

---

### 步骤7：完成通知

| 属性 | 描述 |
|-----|------|
| 步骤编号 | S7 |
| 步骤名称 | 完成通知 |
| 执行角色 | 系统管理员 |
| 输入 | 离职处理完成 |
| 输出 | 完成通知 |

**通知对象：**
- HR专员
- 部门管理员
- 安全管理员

## 四、异常流程

### 4.1 紧急离职处理

| 场景 | 处理方案 |
|-----|---------|
| 员工突然离职 | 立即禁用账号，后续补办手续 |
| 存在安全风险 | 立即禁用并通知安全管理员 |

### 4.2 交接未完成

| 场景 | 处理方案 |
|-----|---------|
| 工作交接未完成 | 延期禁用，或保留部分权限 |
| 数据未转移 | 协助完成数据备份和转移 |

## 五、业务规则汇总

| 规则编号 | 规则描述 | 适用步骤 |
|---------|---------|---------|
| BR-001 | 禁用操作在最后工作日执行 | S4 |
| BR-002 | 禁用后保留用户数据 | S4 |
| BR-003 | 必须完成交接才能禁用 | S3-S4 |
| BR-004 | 自动记录所有操作日志 | S6 |
| BR-005 | 紧急情况下可立即禁用 | 异常流程 |

## 六、流程指标

| 指标 | 目标值 | 说明 |
|-----|-------|------|
| 账号禁用及时率 | 100% | 最后工作日当天完成 |

| 交接完成率 | ≥ 95% | 工作交接完成比例 |
| 处理时间 | ≤ 1工作日 | 从通知到完成 |
