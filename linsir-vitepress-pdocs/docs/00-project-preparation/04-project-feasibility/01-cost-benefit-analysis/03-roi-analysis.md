## 3. ROI计算

### 3.1 简单ROI

**公式：**
```
ROI = (总收益 - 总投资) / 总投资 × 100%
```

**计算：**
```
总投资 = 111.66万元
总收益（5年） = 760.71万元
总成本（5年） = 111.66 + 15×5 = 186.66万元
净收益 = 760.71 - 186.66 = 574.05万元

ROI = 574.05 / 111.66 × 100% = 514.1%
```

### 3.2 年化ROI

**公式：**
```
年化ROI = [(1 + ROI)^(1/年数) - 1] × 100%
```

**计算：**
```
年化ROI = [(1 + 5.141)^(1/5) - 1] × 100%
        = [1.438 - 1] × 100%
        = 43.8%
```

### 3.3 ROI对比

| 指标 | 数值 | 行业参考 |
|-----|------|---------|
| 5年ROI | 514.1% | >100%为优秀 |
| 年化ROI | 43.8% | >15%为良好 |
| **结论** | **优秀** | 远高于行业平均水平 |

## 4. 投资回收期

### 4.1 静态回收期

**计算过程：**

| 年份 | 净现金流（万元） | 累计现金流（万元） | 未回收投资（万元） |
|-----|-----------------|-------------------|-------------------|
| 第0年 | -111.66 | -111.66 | 111.66 |
| 第1年 | +124.57 | +12.91 | 0 |

**回收期计算：**
```
回收期 = 1年 - (12.91 / 124.57) = 0.9年 ≈ 11个月
```

### 4.2 动态回收期（考虑贴现）

**贴现现金流计算：**

| 年份 | 净现金流（万元） | 贴现因子（8%） | 贴现现金流（万元） | 累计贴现现金流（万元） |
|-----|-----------------|---------------|-------------------|----------------------|
| 第0年 | -111.66 | 1.000 | -111.66 | -111.66 |
| 第1年 | +124.57 | 0.926 | +115.35 | +3.69 |
| 第2年 | +130.55 | 0.857 | +111.88 | +115.57 |
| 第3年 | +136.83 | 0.794 | +108.64 | +224.21 |

**回收期计算：**

## 5. NPV计算

### 5.1 净现值（NPV）

**公式：**
```
NPV = Σ(现金流_t / (1 + r)^t)
```

**计算：**
```
NPV = -111.66 + 115.35 + 111.88 + 108.64 + 105.41 + 102.38
    = 432.00万元
```

### 5.2 NPV分析

| 指标 | 数值 | 评价标准 | 结论 |
|-----|------|---------|------|
| NPV | 432.00万元 | >0 | 项目可行 |
| **结论** | **NPV > 0** | 项目创造正价值 | 强烈推荐 |

## 8. 盈亏平衡分析

### 8.1 盈亏平衡点

**计算：**
```
盈亏平衡收益 = 总投资 / 使用年限 + 年运维成本
             = 111.66 / 5 + 15
             = 22.33 + 15
             = 37.33万元/年
```

### 8.2 安全边际

```
安全边际 = (预期收益 - 盈亏平衡收益) / 预期收益 × 100%
         = (139.57 - 37.33) / 139.57 × 100%
         = 73.3%
```

**结论：** 安全边际高达73.3%，收益可下降73%项目仍不亏损，风险极低。
