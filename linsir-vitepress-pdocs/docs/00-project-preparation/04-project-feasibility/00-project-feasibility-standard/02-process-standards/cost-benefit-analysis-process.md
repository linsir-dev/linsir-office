## 1. 流程目的

规范项目成本效益分析工作，确保投资评估的科学性和一致性，为项目决策提供可靠的财务依据。

## 2. 适用范围

适用于所有需要进行投资评估的项目，特别是：
- 新建系统项目
- 重大升级项目
- 基础设施建设项目

## 4. 详细步骤

### 步骤1：确定分析范围

**输入：**
- 项目需求文档
- 技术可行性报告
- 项目计划草案

**活动：**
1. 明确项目边界和范围
2. 确定分析假设（工期、团队规模、贴现率等）
3. 确定分析年限（通常3-5年）
4. 识别关键利益相关方

**输出：**
- 分析范围说明书
- 假设条件清单

### 步骤2：成本估算

#### 2.1 人力成本估算

**估算方法：**
```
人力成本 = Σ(角色人数 × 月成本 × 投入月数)
```

**角色分类：**
- 项目管理：项目经理
- 技术管理：架构师、技术负责人
- 开发团队：前端开发、后端开发
- 质量保障：测试工程师
- 运维支持：运维工程师

**参考模板：**

| 角色 | 人数 | 月成本（万元） | 投入月数 | 小计（万元） |
|-----|------|---------------|---------|-------------|
| 项目经理 | 1 | 2.5 | 6 | 15.0 |
| 系统架构师 | 1 | 3.0 | 6 | 18.0 |
| 开发工程师 | 4 | 2.0 | 6 | 48.0 |
| 测试工程师 | 1 | 1.5 | 4 | 6.0 |
| 运维工程师 | 1 | 1.5 | 2 | 3.0 |
| **合计** | **8** | - | - | **90.0** |

#### 2.2 硬件/云服务成本估算

**成本项：**
- 开发环境服务器
- 测试环境服务器
- 生产环境服务器
- 数据库服务器
- 缓存服务器
- 负载均衡
- 存储和CDN

**参考模板：**

| 资源 | 配置 | 数量 | 单价（元/月） | 月数 | 小计（元） |
|-----|------|------|--------------|------|-----------|
| 应用服务器 | 8核16G | 2 | 800 | 12 | 19,200 |
| 数据库服务器 | 8核16G | 2 | 1,200 | 12 | 28,800 |
| **合计** | - | - | - | - | **48,000** |

#### 2.3 软件许可成本估算

**开源软件（免费）：**
- 记录使用的开源软件及许可类型
- 确认无隐藏成本

**商业软件/服务：**
- 域名证书
- 代码托管服务
- 监控服务
- 第三方组件许可

#### 2.4 培训成本估算

**内部培训：**
- 培训讲师成本（内部讲师按工时计算）
- 培训材料成本
- 培训场地成本

**外部培训：**
- 培训课程费用
- 差旅费用

#### 2.5 其他成本估算

- 差旅费
- 会议费
- 办公用品
- 第三方服务（安全测试、性能测试）
- 应急储备（通常5-10%）

### 步骤3：收益分析

#### 3.1 直接收益分析

**效率提升收益：**
```
效率收益 = 节省工时 × 人力成本
```

**常见收益项：**
- 流程效率提升（如审批流程缩短）
- 人工操作减少（如自动化处理）
- 问题处理效率提升（如自助服务）

**参考模板：**

| 收益项 | 月均处理量 | 节省时间/次 | 人力成本 | 月收益 | 年收益 |
|-------|-----------|------------|---------|--------|--------|
| 流程A优化 | 200次 | 3小时 | 80元/时 | 48,000 | 57.6万 |
| 流程B自动化 | 150次 | 0.5小时 | 100元/时 | 7,500 | 9万 |

**人力节省收益：**
- 运维人力节省
- 客服人力节省
- 管理人力节省

#### 3.2 间接收益分析

**用户体验提升：**
- 用户满意度提升
- 学习成本降低
- 工作效率提升

**安全合规收益：**
- 安全风险降低
- 合规成本节省
- 审计便利性

**业务价值收益：**
- 数据质量提升
- 决策支持能力
- 业务敏捷性

**品牌价值收益：**
- 企业形象提升
- 员工满意度
- 人才吸引力

### 步骤4：ROI计算

#### 4.1 关键指标计算

**投资回报率（ROI）：**
```
ROI = (总收益 - 总投资) / 总投资 × 100%
```

**投资回收期：**
```
回收期 = 累计现金流转正所需时间
```

**净现值（NPV）：**
```
NPV = Σ(现金流_t / (1 + r)^t)
```
其中 r 为贴现率

**内部收益率（IRR）：**
```
使 NPV = 0 的贴现率
```

#### 4.2 评价标准

| 指标 | 优秀 | 良好 | 可接受 | 不可接受 |
|-----|------|------|--------|---------|
| 5年ROI | >100% | 50-100% | 20-50% | <20% |
| 年化ROI | >15% | 10-15% | 5-10% | <5% |
| 回收期 | <1年 | 1-2年 | 2-3年 | >3年 |
| NPV | >0 | - | - | <0 |
| IRR | >贴现率 | 接近贴现率 | - | <贴现率 |

### 步骤5：敏感性分析

#### 5.1 单因素敏感性分析

**收益变化影响：**

| 收益实现率 | 5年ROI | 回收期 | 结论 |
|-----------|--------|--------|------|
| 100% | ?% | ?个月 | - |
| 80% | ?% | ?个月 | - |
| 60% | ?% | ?个月 | - |
| 40% | ?% | ?个月 | - |

**成本变化影响：**

| 成本变化 | 5年ROI | 回收期 | 结论 |
|---------|--------|--------|------|
| +20% | ?% | ?个月 | - |
| 基准 | ?% | ?个月 | - |
| -20% | ?% | ?个月 | - |

#### 5.2 双因素敏感性分析

构建收益-成本矩阵，评估组合影响。

#### 5.3 盈亏平衡分析

```
盈亏平衡收益 = 总投资 / 使用年限 + 年运维成本
安全边际 = (预期收益 - 盈亏平衡收益) / 预期收益
```

### 步骤6：编写分析报告

**报告结构：**
1. 执行摘要
2. 成本分析
3. 收益分析
4. ROI分析
5. 敏感性分析
6. 风险分析
7. 建议
8. 结论

**关键输出：**
- 成本估算表
- 收益预测表
- 现金流表
- ROI计算表
- 敏感性分析表

### 步骤7：评审与确认

**评审流程：**
1. 项目经理初审
2. 财务部门审核
3. 管理层审批

**评审要点：**
- 成本估算完整性
- 收益预测合理性
- 假设条件有效性
- 风险识别充分性

## 6. 最佳实践

### 6.1 成本估算
- 预留10-15%应急储备
- 考虑隐性成本（管理成本、沟通成本）
- 参考历史项目数据

### 6.2 收益估算
- 保守估计，避免过度乐观
- 区分确定收益和预期收益
- 建立收益度量机制

### 6.3 风险应对
- 识别关键风险因素
- 制定风险应对预案
- 定期回顾和更新
