## 6. 风险应对计划

### 6.1 进度风险应对

| 风险 | 应对措施 | 责任人 |
|-----|---------|--------|
| 需求变更 | 严格变更控制，预留缓冲时间 | 项目经理 |
| 人员不足 | 提前招聘，准备外包方案 | 项目经理 |
| 技术难点 | 提前预研，技术攻关小组 | 架构师 |
| 外部依赖 | 提前沟通，准备Mock服务 | 项目经理 |

### 6.2 缓冲策略

| 缓冲类型 | 时长 | 说明 |
|---------|------|------|
| 项目缓冲 | 2周 | 放在项目末尾 |
| 阶段缓冲 | 各阶段末 | 每个阶段预留1-2天 |
| 资源缓冲 | 10% | 人力资源预留 |
