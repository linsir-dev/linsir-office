# 项目范围概述

**文档编号：** SYS-PF-PP-001  
**版本：** 1.0  
**日期：** 2026-03-10  
**编制：** 项目经理  
**审核：** 审核通过

---

## 1. 项目目标

### 1.1 业务目标

| 目标 | 描述 | 成功标准 |
|-----|------|---------|
| 统一认证 | 实现单点登录（SSO），用户只需一套账号密码访问所有系统 | 用户登录一次即可访问所有集成系统 |
| 统一权限 | 建立集中权限管理平台，简化权限申请和管理流程 | 权限申请时间从3天缩短至1天 |
| 系统集成 | 与ERP、OA、HR、CRM系统实现无缝集成 | 数据实时同步，业务流程贯通 |
| 提升体验 | 提供统一的用户界面和一致的操作体验 | 用户满意度提升至90%以上 |

### 1.2 技术目标

| 目标 | 描述 | 指标 |
|-----|------|------|
| 高性能 | 系统能够支撑高并发访问 | 支持1000+并发用户 |
| 高可用 | 系统具备高可用性 | 可用性达到99.9% |
| 高安全 | 系统满足安全合规要求 | 通过等保三级认证 |
| 易扩展 | 系统架构支持未来扩展 | 支持新系统快速接入 |

## 2. 项目范围

### 2.1 包含范围（In Scope）

#### 2.1.1 功能范围

| 模块 | 功能 | 说明 |
|-----|------|------|
| **统一认证** | 单点登录（SSO） | 基于OAuth 2.0协议实现 |
| | 多因素认证 | 支持短信、邮箱验证码 |
| | 密码管理 | 密码重置、修改、强度检查 |
| | 会话管理 | 登录状态管理、超时处理 |
| **统一权限** | 角色管理 | RBAC权限模型 |
| | 权限分配 | 菜单、按钮、数据权限 |
| | 权限申请 | 在线权限申请流程 |
| | 权限审计 | 权限变更日志记录 |
| **系统管理** | 用户管理 | 用户增删改查、导入导出 |
| | 组织管理 | 部门、岗位管理 |
| | 菜单管理 | 系统菜单配置 |
| | 日志审计 | 操作日志、登录日志 |
| **系统集成** | ERP集成 | 与ERP系统用户同步 |
| | OA集成 | 与OA系统单点登录 |
| | HR集成 | 与HR系统组织架构同步 |
| | CRM集成 | 与CRM系统权限对接 |

#### 2.1.2 技术范围

| 项目 | 说明 |
|-----|------|
| 前端开发 | Web前端界面开发（Vue 3） |
| 后端开发 | 服务端API开发（Spring Boot） |
| 数据库设计 | 数据库表结构设计 |
| 接口开发 | 与外部系统的接口开发 |
| 安全实现 | 认证、授权、加密等安全功能 |
| 部署实施 | 系统部署、配置、上线 |

#### 2.1.3 服务范围

| 服务 | 说明 |
|-----|------|
| 需求分析 | 详细需求调研和分析 |
| 系统设计 | 架构设计、详细设计 |
| 开发实施 | 编码开发、单元测试 |
| 系统测试 | 集成测试、性能测试、UAT测试 |
| 用户培训 | 管理员培训、用户培训 |
| 上线支持 | 上线部署、试运行支持 |
| 文档交付 | 需求文档、设计文档、操作手册 |

### 2.2 不包含范围（Out of Scope）

| 项目 | 说明 | 原因 |
|-----|------|------|
| 外部系统改造 | ERP/OA/HR/CRM系统的内部改造 | 由各自系统团队负责 |
| 移动端APP | iOS/Android原生APP开发 | 本期仅支持Web端 |
| 硬件采购 | 服务器、网络设备等硬件采购 | 由IT基础设施团队负责 |
| 第三方服务 | 短信、邮件等第三方服务费用 | 由运营费用承担 |
| 非标准定制 | 超出标准功能范围的定制开发 | 需单独评估 |
| 数据迁移 | 历史数据迁移（超过1年） | 需单独评估 |
| 长期运维 | 上线后超过3个月的运维支持 | 转入运维团队 |

## 4. 验收标准

### 4.1 功能验收标准

| 功能模块 | 验收标准 |
|---------|---------|
| 统一认证 | 用户可使用一套账号密码登录所有集成系统 |
| 统一权限 | 权限申请流程在线完成，审批时间<1天 |

| 系统集成 | 与4个外部系统实现数据同步和单点登录 |

### 4.2 性能验收标准

| 指标 | 标准值 | 测试方法 |
|-----|--------|---------|

| 页面加载时间 | ≤2s | 性能测试 |
| 系统可用性 | ≥99.9% | 监控统计 |

### 4.3 安全验收标准

| 指标 | 标准值 | 测试方法 |
