## 1. 需求背景

### 1.1 业务背景
随着公司规模扩大，传统的纸质审批和线下沟通方式已无法满足高效办公需求。OA系统旨在实现办公流程的数字化、自动化，提升组织协同效率。

### 1.2 战略定位
OA系统是公司**办公协同的核心平台**，定位为：
- **流程审批中心**：统一各类审批流程，实现无纸化办公
- **协同办公平台**：提供日程、会议、任务等协作工具
- **信息发布渠道**：公告、新闻、知识的统一发布平台
- **移动办公入口**：支持随时随地办公，提升响应速度

### 1.3 痛点分析
- 审批流程依赖纸质单据，效率低下，平均审批周期3-5天
- 跨部门协作困难，信息传递不畅
- 会议安排冲突频繁，会议室资源浪费
- 公告通知传达不及时，员工获取信息滞后
- 缺乏统一的任务跟踪机制，工作进度不透明

### 1.4 目标价值
- 审批效率提升80%，平均审批周期缩短至1天内
- 实现100%核心业务流程线上化
- 会议资源利用率提升50%
- 信息传达及时率提升至95%以上
- 任务完成可视化管理

## 5. 业务流程

### 流程一：请假审批流程

```
参与者：员工、直属领导、HR专员

正常流程：
1. 员工在OA系统提交请假申请
2. 填写请假类型、时间、原因
3. 系统自动计算剩余假期天数
4. 提交给直属领导审批
5. 领导审批通过后，转HR备案
6. HR确认假期余额，流程结束
7. 员工收到审批结果通知

异常流程：
- 异常1：假期余额不足
  → 系统提示余额不足，无法提交
- 异常2：领导长时间未审批（超过2天）
  → 系统自动提醒领导，超过3天可催办
- 异常3：领导拒绝请假
  → 员工收到拒绝通知，可修改后重新提交或取消
```

### 流程二：报销审批流程

```
参与者：员工、部门经理、财务专员

正常流程：
1. 员工提交报销申请，上传发票照片
2. 填写报销类型、金额、事由
3. 部门经理审批（金额>5000需总监审批）
4. 财务专员审核票据和金额
5. 财务专员确认打款
6. 员工收到报销完成通知

异常流程：
- 异常1：发票不清晰或不合规
  → 财务退回，员工需重新上传
- 异常2：金额超过预算
  → 需额外说明，转更高级领导审批
```

## 6. 业务规则

| 规则编号 | 规则名称 | 规则描述 | 优先级 |
|---------|---------|---------|--------|
| BR-001 | 审批时效 | 普通审批需在2个工作日内完成；紧急审批需在4小时内完成，由发起人标记并填写紧急原因 | 高 |
| BR-002 | 假期余额检查 | 提交请假申请时，系统自动校验剩余假期余额（年假+调休-已用） | 高 |

| BR-004 | 会议室冲突 | 同一会议室同一时段不可重复预定 | 高 |
| BR-005 | 公告置顶限制 | 同时置顶公告不超过3条 | 低 |
| BR-006 | 任务提醒 | 任务到期前1天和当天各提醒一次 | 中 |
| BR-007 | 采购限额 | 单笔采购超过5000元需部门总监审批；超过20000元需财务总监审批 | 高 |
| BR-008 | 合同限额 | 合同金额超过10万元需总经理审批 | 高 |
| BR-009 | 用印登记 | 用印完成后必须登记用印文件份数和用途 | 中 |

## 7. 非功能性需求

### 7.1 性能需求
- 页面加载时间 < 3秒（1000条数据、WiFi网络条件下）
- 审批提交响应时间 < 2秒
- 支持并发用户数 > 300
- 系统总用户数 > 2000
- 附件存储：OSS存储，总容量100GB，单文件最大10MB

### 7.2 集成需求
- 与System系统对接，复用用户、部门、权限数据
- 使用System系统提供的统一认证服务（SSO）
- 审批消息可推送至企业微信/钉钉（V2.0）
- 会议管理支持Outlook日历集成（V2.0）

### 7.3 移动端需求
- **V1.0版本**：支持H5页面，适配手机浏览器
- **V2.0版本**：开发原生APP或小程序

## 8. 数据字典

### 8.1 审批状态

| 状态值 | 状态名称 | 说明 |
|-------|---------|------|
| 0 | 草稿 | 申请已保存但未提交 |
| 1 | 审批中 | 申请已提交，正在审批流程中 |
| 2 | 已通过 | 审批流程完成，申请通过 |
| 3 | 已拒绝 | 审批流程完成，申请被拒绝 |
| 4 | 已撤回 | 申请人主动撤回申请 |
| 5 | 已转交 | 审批人转交给他人审批 |

状态流转：
```
草稿 → 审批中（提交）
审批中 → 已通过（最终审批人同意）
审批中 → 已拒绝（任一审批人拒绝）
审批中 → 已撤回（申请人撤回）
审批中 → 已转交（审批人转交）
```

### 8.2 假期类型

| 类型值 | 类型名称 | 计算规则 |
|-------|---------|---------|
| 1 | 年假 | 按工龄计算，每年1-10天 |
| 2 | 病假 | 每年最多30天，需医院证明 |
| 3 | 事假 | 无薪假，每年最多15天 |
| 4 | 调休 | 加班调休，按加班时长计算 |
| 5 | 婚假 | 法定3天，晚婚增加7天 |
| 6 | 产假 | 按国家规定执行 |

### 8.3 会议状态

| 状态值 | 状态名称 | 说明 |
|-------|---------|------|
| 0 | 待定 | 会议创建，等待参会人确认 |
| 1 | 已确认 | 所有参会人已确认参加 |
| 2 | 进行中 | 会议正在进行中 |
| 3 | 已结束 | 会议已结束 |
| 4 | 已取消 | 会议被取消 |

### 8.4 任务状态

| 状态值 | 状态名称 | 说明 |
|-------|---------|------|
| 0 | 待办 | 任务已分配，等待处理 |
| 1 | 进行中 | 任务已开始处理 |
| 2 | 已完成 | 任务已完成 |
