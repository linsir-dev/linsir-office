## 五、评审标准

### 5.1 通过标准

评审结论分为三种：

| 结论 | 说明 | 后续动作 |
|-----|------|---------|
| **通过** | 设计满足要求，无需修改或仅需微调 | 建立基线 |
| **有条件通过** | 设计基本满足要求，存在少量问题 | 修改后确认 |
| **不通过** | 设计存在重大问题 | 重新设计 |

### 5.2 问题分级

| 级别 | 说明 | 处理要求 |
|-----|------|---------|
| **严重** | 影响功能、性能、安全 | 必须修改 |
| **中等** | 影响质量、可维护性 | 建议修改 |
| **轻微** | 风格、注释等细节 | 可选修改 |
