# 原型设计规范

## 1. 概述

### 1.1 文档目的

本文档定义了系统原型设计的规范和标准，确保原型设计的一致性、可用性和可维护性。

### 1.2 适用范围

适用于系统所有功能模块的原型设计，包括：
- 用户管理模块
- 组织架构模块
- 权限管理模块
- 系统配置模块

### 1.3 原型设计目标

- **验证交互流程**：验证用户任务的完成路径是否合理
- **发现体验问题**：在开发前发现潜在的交互问题
- **沟通设计意图**：为开发团队提供清晰的设计参考
- **用户测试**：支持用户可用性测试

---

## 2. 原型设计原则

### 2.1  fidelity 层级

| 层级 | 名称 | 描述 | 适用场景 |
|------|------|------|----------|
| **Low** | 低保真 | 线框图，无视觉细节 | 早期概念验证 |
| **Medium** | 中保真 | 有基础视觉，简化交互 | 内部评审 |
| **High** | 高保真 | 接近真实产品，完整交互 | 用户测试、开发参考 |

### 2.2 设计原则

#### 2.2.1 一致性原则
- 统一使用设计系统定义的组件
- 保持交互模式的一致性
- 遵循既定的页面布局规范

#### 2.2.2 完整性原则
- 覆盖所有用户操作流程
- 包含正常流程和异常流程
- 考虑边界情况和空状态

#### 2.2.3 可测试性原则
- 关键流程必须可交互
- 状态变化要有明确反馈
- 支持用户操作路径的完整模拟

## 3. 原型设计规范

### 3.1 页面结构规范

#### 3.1.1 页面布局

```
┌─────────────────────────────────────────────────────────────┐
│  顶部导航栏 (64px)                                           │
├──────────────┬──────────────────────────────────────────────┤
│              │                                              │
│  侧边菜单    │           内容区域                            │
│  (200px)     │           (自适应)                            │
│              │                                              │
│              │                                              │
│              │                                              │
│              │                                              │
└──────────────┴──────────────────────────────────────────────┘
```

#### 3.1.2 页面元素层级

| 层级 | 元素 | z-index | 说明 |
|------|------|---------|------|
| 1 | 页面内容 | auto | 基础内容层 |
| 10 | 固定头部 | 100 | 固定在顶部 |
| 10 | 固定侧边栏 | 100 | 固定在左侧 |
| 20 | 下拉菜单 | 200 | 悬浮层 |
| 30 | 模态框遮罩 | 300 | 遮罩层 |
| 40 | 模态框内容 | 400 | 弹窗层 |
| 50 | 消息提示 | 500 | 通知层 |
| 60 | 加载层 | 600 | 最高层级 |

### 3.2 交互规范

#### 3.2.1 页面转场

| 转场类型 | 动画效果 | 时长 | 缓动函数 |
|----------|----------|------|----------|
| 页面切换 | 淡入淡出 | 300ms | ease-in-out |
| 侧边栏展开 | 滑动 | 200ms | ease-out |
| 弹窗出现 | 缩放+淡入 | 200ms | cubic-bezier(0.4, 0, 0.2, 1) |
| 抽屉滑出 | 从右滑入 | 300ms | ease-out |
| 下拉展开 | 高度展开 | 200ms | ease-in-out |

#### 3.2.2 交互反馈

| 交互类型 | 反馈方式 | 延迟 |
|----------|----------|------|
| 按钮点击 | 颜色变化/缩放 | 即时 |
| 链接悬停 | 下划线/颜色变化 | 即时 |
| 输入框聚焦 | 边框高亮 | 即时 |
| 加载状态 | 加载动画 | 即时 |
| 操作成功 | Toast提示 | 即时 |
| 操作失败 | 错误提示 | 即时 |

#### 3.2.3 手势支持（移动端）

| 手势 | 操作 | 反馈 |
|------|------|------|
| 点击 | 选择/激活 | 视觉反馈 |
| 长按 | 上下文菜单 | 震动+菜单弹出 |
| 滑动 | 列表操作/页面切换 | 跟随手指移动 |
| 下拉 | 刷新 | 加载指示器 |
| 上拉 | 加载更多 | 加载指示器 |
| 捏合 | 缩放（图片/地图） | 内容缩放 |

### 3.3 组件交互规范

#### 3.3.1 按钮

| 状态 | 视觉表现 | 交互说明 |
|------|----------|----------|
| 默认 | 主色填充 | 可点击 |
| 悬停 | 颜色加深 | 提示可点击 |
| 按下 | 缩放0.98 | 确认点击 |
| 禁用 | 灰色，cursor:not-allowed | 不可点击 |
| 加载 | 加载图标+文字 | 等待中 |

#### 3.3.2 表单输入

| 状态 | 视觉表现 | 交互说明 |
|------|----------|----------|
| 默认 | 灰色边框 | 等待输入 |
| 聚焦 | 主色边框+阴影 | 当前输入框 |
| 错误 | 红色边框+错误提示 | 验证失败 |
| 成功 | 绿色边框+成功图标 | 验证通过 |
| 禁用 | 灰色背景 | 不可编辑 |

#### 3.3.3 表格

| 交互 | 行为 | 说明 |
|------|------|------|
| 行悬停 | 背景色变化 | 高亮当前行 |
| 行点击 | 选中/展开详情 | 单选或多选 |
| 表头点击 | 排序 | 升序/降序切换 |
| 复选框 | 批量选择 | 支持全选 |
| 操作按钮 | 悬停显示 | 节省空间 |

#### 3.3.4 弹窗/抽屉

| 类型 | 触发方式 | 关闭方式 | 遮罩点击 |
|------|----------|----------|----------|
| 确认框 | 点击删除等危险操作 | 确认/取消 | 可关闭 |
| 信息框 | 点击详情 | 关闭按钮 | 可关闭 |
| 表单弹窗 | 点击新建/编辑 | 保存/取消 | 不可关闭 |
| 抽屉 | 点击更多操作 | 关闭按钮/遮罩 | 可关闭 |

## 5. 响应式设计规范

### 5.1 断点定义

| 断点 | 宽度 | 设备类型 | 布局调整 |
|------|------|----------|----------|
| xs | < 576px | 手机竖屏 | 单列布局，隐藏侧边栏 |
| sm | 576px - 767px | 手机横屏 | 单列布局，隐藏侧边栏 |
| md | 768px - 991px | 平板 | 侧边栏可折叠 |
| lg | 992px - 1199px | 小桌面 | 标准布局 |
| xl | 1200px - 1599px | 桌面 | 标准布局 |
| xxl | ≥ 1600px | 大桌面 | 更宽内容区 |

### 5.2 移动端适配

#### 5.2.1 导航适配

- **顶部导航**：简化图标，收起次要功能
- **侧边菜单**：改为抽屉式，点击汉堡菜单展开
- **面包屑**：简化显示，只保留上一级

#### 5.2.2 内容适配

- **表格**：改为卡片列表，横向滚动或折叠列
- **表单**：全宽输入框，垂直排列
- **图表**：保持比例，支持手势缩放
- **弹窗**：全屏或底部抽屉

#### 5.2.3 交互适配

- 增大点击区域（最小44px）
- 支持滑动手势
- 支持下拉刷新
- 支持上拉加载更多

## 6. 原型交付规范

### 6.1 交付内容

| 内容 | 格式 | 说明 |
|------|------|------|
| 可交互原型 | HTML/在线链接 | 支持点击、跳转 |
| 原型说明文档 | Markdown | 详细交互说明 |
| 页面流程图 | PNG/PDF | 页面间跳转关系 |
| 状态说明 | Markdown | 各状态定义 |

### 6.2 命名规范

| 类型 | 命名规则 | 示例 |
|------|----------|------|
| 页面 | `模块_功能_状态` | `user_list_default` |
| 组件 | `组件类型_变体` | `button_primary` |
| 交互 | `动作_对象_结果` | `click_submit_success` |
| 状态 | `状态_描述` | `state_loading` |

### 6.3 版本管理

| 版本号 | 规则 | 示例 |
|--------|------|------|
| 主版本 | 重大结构调整 | v1.0.0 |
| 次版本 | 新增页面/功能 | v1.1.0 |
| 修订版本 | 细节优化/修复 | v1.1.1 |

## 7. 原型评审检查清单

### 7.1 功能完整性

- [ ] 覆盖所有用户故事

- [ ] 边界情况处理

- [ ] 操作流程符合用户习惯

- [ ] 使用设计系统组件
