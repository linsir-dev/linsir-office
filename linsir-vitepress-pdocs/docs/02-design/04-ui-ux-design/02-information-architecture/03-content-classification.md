## 二、内容分类原则

### 2.1 核心原则

| 原则 | 描述 | 应用 |
|------|------|------|
| **用户中心** | 以用户任务为导向组织内容 | 按业务流程分类 |
| **逻辑清晰** | 分类逻辑明确，避免交叉 | 功能模块独立 |
| **可扩展性** | 支持未来内容扩展 | 预留分类空间 |
| **一致性** | 分类标准统一 | 全局统一规范 |
| **简洁性** | 避免过度分类 | 层级不超过3层 |

### 2.2 分类维度

| 维度 | 说明 | 示例 |
|------|------|------|
| **功能维度** | 按功能模块分类 | 用户管理、组织架构 |
| **角色维度** | 按用户角色分类 | 管理员功能、普通用户功能 |
| **场景维度** | 按使用场景分类 | 日常操作、系统配置 |
| **数据维度** | 按数据类型分类 | 用户数据、日志数据 |

## 三、功能内容分类

### 3.1 一级分类（系统模块）

```
系统平台
├── 用户管理
├── 组织架构
├── 权限管理
├── 系统监控
├── 日志管理
└── 系统配置
```

### 3.2 用户管理分类

```
用户管理
├── 用户数据管理
│   ├── 用户列表
│   ├── 用户查询
│   ├── 用户详情
│   └── 用户统计
├── 用户生命周期
│   ├── 用户创建
│   ├── 用户编辑
│   ├── 用户启用/禁用
│   └── 用户删除
├── 批量操作
│   ├── 批量导入
│   ├── 批量导出
│   └── 批量更新
└── 个人中心
    ├── 个人信息
    ├── 头像管理
    └── 密码修改
```

#### 3.2.1 用户数据分类

| 数据类别 | 数据项 | 展示优先级 |
|---------|--------|-----------|
| **基础信息** | 用户名、姓名、手机号、邮箱 | P0 |
| **组织信息** | 部门、岗位、职级 | P0 |
| **状态信息** | 账号状态、创建时间、最后登录 | P1 |
| **扩展信息** | 头像、备注、标签 | P2 |

### 3.3 组织架构分类

```
组织架构
├── 部门管理
│   ├── 部门树
│   ├── 部门详情
│   ├── 部门成员
│   └── 部门统计
├── 组织架构图
│   ├── 层级视图
│   ├── 矩阵视图
│   └── 导出图片
└── 岗位管理
    ├── 岗位列表
    ├── 岗位分类
    └── 岗位职责
```

#### 3.3.1 部门层级分类

| 层级 | 名称 | 示例 | 管理范围 |
|-----|------|------|---------|
| L1 | 公司/集团 | 总公司 | 全公司 |
| L2 | 事业部 | 技术事业部 | 事业部内 |
| L3 | 部门 | 研发部 | 部门内 |
| L4 | 小组 | 前端组 | 小组内 |

### 3.4 权限管理分类

```
权限管理
├── 角色管理
│   ├── 角色列表
│   ├── 角色创建
│   ├── 角色编辑
│   └── 角色删除
├── 权限分配
│   ├── 菜单权限
│   ├── 操作权限
│   └── 数据权限
└── 权限审计

    └── 权限变更记录
```

#### 3.4.1 权限类型分类

| 权限类型 | 说明 | 控制粒度 |
|---------|------|---------|
| **菜单权限** | 控制页面访问 | 页面级别 |
| **操作权限** | 控制按钮操作 | 按钮级别 |
| **数据权限** | 控制数据范围 | 数据行/字段级别 |
| **字段权限** | 控制字段可见 | 字段级别 |

### 3.5 系统监控分类

```
系统监控
├── 用户监控
│   ├── 在线用户
│   ├── 活跃用户
│   └── 用户行为分析
└── 系统状态
    ├── 服务器状态
    ├── 数据库状态
    └── 应用状态
```

### 3.6 日志管理分类

```
日志管理
├── 操作日志
│   ├── 增删改操作
│   ├── 查询操作
│   └── 登录/登出
└── 系统日志
    ├── 错误日志
    ├── 警告日志
    └── 信息日志
```

#### 3.6.1 日志级别分类

| 级别 | 颜色 | 说明 | 保留时长 |
|-----|------|------|---------|
| **ERROR** | 🔴 红色 | 错误日志 | 90天 |
| **WARN** | 🟡 黄色 | 警告日志 | 60天 |
| **INFO** | 🔵 蓝色 | 信息日志 | 30天 |
| **DEBUG** | ⚪ 灰色 | 调试日志 | 7天 |

### 3.7 系统配置分类

```
系统配置
├── 参数配置
│   ├── 基础参数
│   ├── 安全参数
│   └── 业务参数
└── 字典管理
    ├── 用户字典
    ├── 系统字典
    └── 业务字典
```

## 五、信息层级分类

### 5.1 页面信息层级

```
页面信息层级
├── L1: 页面标题
│   └── 当前页面名称
├── L2: 模块标题
│   └── 功能模块名称
├── L3: 区块标题
│   └── 内容区块名称
└── L4: 内容项
    └── 具体信息项
```

### 5.2 表单信息层级

```
表单信息层级
├── 表单标题
│   └── 表单名称 + 操作类型（创建/编辑）
├── 分组标题
│   └── 基础信息、联系信息、权限设置
├── 字段标签
│   └── 用户名、手机号、邮箱
└── 字段输入
    └── 输入框、选择器、开关
```

#### 5.2.1 表单字段分类

| 分类 | 字段示例 | 必填比例 |
|------|---------|---------|
| **基础信息** | 用户名、姓名、手机号 | 100% |
| **联系信息** | 邮箱、地址、紧急联系人 | 50% |
| **工作信息** | 部门、岗位、入职日期 | 80% |
| **权限信息** | 角色、数据范围 | 100% |
| **扩展信息** | 头像、备注、标签 | 0% |

### 5.3 列表信息层级

```
列表信息层级
├── 列表标题
│   └── 列表名称 + 统计数量
├── 筛选区域
│   ├── 搜索框
│   ├── 筛选条件
│   └── 快捷筛选
├── 操作区域
│   ├── 批量操作
│   ├── 新建按钮
│   └── 导出按钮
├── 表格区域
│   ├── 表头
│   ├── 数据行
│   └── 操作列
└── 分页区域
    └── 分页器 + 每页条数
```

#### 5.3.1 列表字段优先级

| 优先级 | 字段类型 | 说明 |
|-------|---------|------|
| P0 | 关键标识 | 用户名、姓名 |
| P0 | 状态信息 | 账号状态、审核状态 |
| P1 | 组织信息 | 部门、岗位 |
| P1 | 时间信息 | 创建时间、更新时间 |
| P2 | 扩展信息 | 备注、标签 |

## 六、搜索与筛选分类

### 6.1 搜索类型分类

| 搜索类型 | 适用场景 | 示例 |
|---------|---------|------|
| **全局搜索** | 跨模块搜索 | 顶部搜索栏 |
| **模块搜索** | 当前模块内搜索 | 用户列表搜索 |
| **字段搜索** | 指定字段搜索 | 按手机号搜索 |
| **高级搜索** | 多条件组合搜索 | 筛选面板 |

### 6.2 筛选条件分类

```
筛选条件
├── 时间筛选
│   ├── 今天/昨天/本周/本月
│   ├── 最近7天/30天/90天
│   └── 自定义时间范围
├── 状态筛选
│   ├── 启用/禁用
│   ├── 已认证/未认证
│   └── 在线/离线
├── 组织筛选
│   ├── 按部门筛选
│   ├── 按岗位筛选
│   └── 按职级筛选
└── 自定义筛选
    ├── 标签筛选
    └── 属性筛选
```

### 6.3 排序规则分类

| 排序类型 | 默认规则 | 可选规则 |
|---------|---------|---------|
| **时间排序** | 创建时间倒序 | 更新时间、登录时间 |
| **名称排序** | 名称升序 | 拼音排序 |
| **层级排序** | 层级升序 | 自定义排序 |
| **状态排序** | 状态优先级 | 启用在前 |

## 七、通知消息分类

### 7.1 消息类型分类

```
通知消息
├── 系统通知
│   ├── 系统公告
│   ├── 功能更新
│   └── 维护通知
├── 业务通知
│   ├── 审批提醒
│   ├── 任务提醒
│   └── 预警提醒
└── 操作反馈
    ├── 成功提示
    ├── 失败提示
    └── 警告提示
```

### 7.2 消息优先级分类

| 优先级 | 类型 | 展示方式 | 声音提醒 |
|-------|------|---------|---------|
| **紧急** | 系统故障、安全告警 | 弹窗 + 通知栏 | 是 |
| **高** | 审批提醒、任务截止 | 通知栏 + 红点 | 是 |
| **中** | 功能更新、系统公告 | 通知栏 | 否 |
| **低** | 操作成功、提示信息 | 短暂提示 | 否 |

## 八、文件与资源分类

### 8.1 文件类型分类

| 文件类型 | 扩展名 | 处理方式 | 存储位置 |
|---------|--------|---------|---------|
| **图片** | .jpg, .png, .gif | 预览、压缩 | 对象存储 |

| **头像** | .jpg, .png | 裁剪、压缩 | CDN |
