# 原型设计阶段流程标准

## 1. 阶段概述

| 项目 | 内容 |
|------|------|
| **阶段编号** | 4-05 |
| **阶段名称** | 原型设计 |
| **阶段目标** | 制作可交互原型，验证设计方案 |
| **输入** | 视觉设计、交互设计 |
| **输出** | 3个原型文档 |
| **耗时** | 5-7个工作日 |

## 2. 执行流程

```
开始
  │
  ▼
制定原型规范
  │
  ▼
制作可交互原型
  │
  ▼
编写原型说明
  │
  ▼
评审 ──不通过──┬──通过──► 输出3个文档 ──► 结束
                │
                └─────── 返回修改
```

## 3. 核心任务

### 3.1 制定原型规范
**输出**: `01-prototype-specification.md`
**关键活动**:
- 定义原型范围
- 确定交互深度
- 制定制作标准
- 规划页面流程

### 3.2 制作可交互原型
**输出**: `02-interactive-prototype.md`
**关键活动**:
- 搭建原型框架
- 添加页面跳转
- 实现交互效果
- 设计过渡动画

### 3.3 编写原型说明
**输出**: `03-prototype-review-record.md`
**关键活动**:
- 描述原型功能
- 说明交互逻辑
- 记录设计决策
- 准备评审材料
