## 二、线框图设计规范

### 2.1 设计原则

| 原则 | 描述 | 应用 |
|------|------|------|
| **清晰性** | 布局清晰，信息层级分明 | 使用网格系统，统一间距 |
| **一致性** | 相同类型页面结构一致 | 统一布局模板 |
| **可用性** | 符合用户操作习惯 | 重要操作突出，常用功能易达 |
| **响应式** | 支持多设备适配 | 定义断点和适配规则 |

### 2.2 网格系统

```
桌面端 (1920px)
┌─────────────────────────────────────────────────────────────────┐
│  侧边栏(240px)  │           内容区域 (剩余宽度)                    │
│                 │  ┌─────────────────────────────────────────┐   │
│                 │  │  顶部栏 (64px)                           │   │
│                 │  ├─────────────────────────────────────────┤   │
│                 │  │                                         │   │
│                 │  │           页面内容区域                    │   │
│                 │  │         (24px 边距)                      │   │
│                 │  │                                         │   │
│                 │  │                                         │   │
│                 │  └─────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘

内容区域网格: 24列网格系统, 间距 16px
```

### 2.3 间距规范

| 元素 | 尺寸 | 说明 |
|------|------|------|
| 页面边距 | 24px | 内容区域四周 |
| 卡片间距 | 16px | 卡片之间 |
| 表单字段间距 | 24px | 表单字段之间 |
| 按钮间距 | 8px | 按钮之间 |
| 文字行高 | 1.5 | 正文行高 |

│  │  首页    │  │  │                                     │   │  │

### 3.2 布局类型

| 布局类型 | 适用页面 | 特点 |
|---------|---------|------|
| **列表布局** | 用户列表、部门列表 | 筛选区+操作栏+表格+分页 |
| **表单布局** | 用户创建、编辑 | 分组表单+操作按钮 |
| **详情布局** | 用户详情、部门详情 | 信息卡片+操作按钮 |
| **仪表盘布局** | 首页 | 数据卡片+快捷入口+图表 |
| **树形布局** | 部门管理 | 左侧树+右侧详情 |

## 六、响应式适配

### 6.1 断点定义

| 断点 | 宽度范围 | 设备类型 |
|-----|---------|---------|
| xs | < 576px | 手机竖屏 |
| sm | 576px - 768px | 手机横屏/平板竖屏 |
| md | 768px - 992px | 平板横屏 |
| lg | 992px - 1200px | 小型桌面 |
| xl | 1200px - 1600px | 标准桌面 |
| xxl | > 1600px | 大屏桌面 |

### 6.2 布局适配规则

| 布局元素 | 桌面端 | 平板端 | 手机端 |
|---------|--------|--------|--------|
| 侧边栏 | 固定 240px | 可折叠 | 隐藏（抽屉式） |
| 内容区域 | 自适应 | 自适应 | 全宽 |
| 数据卡片 | 4列 | 2列 | 1列 |
| 表格 | 全列显示 | 横向滚动 | 卡片式列表 |
| 表单 | 多列 | 双列 | 单列 |
