## 二、交互设计原则

### 2.1 核心原则

| 原则 | 描述 | 设计体现 |
|------|------|---------|
| **即时反馈** | 用户操作后立即给予反馈 | 按钮点击效果、加载状态 |
| **操作可逆** | 重要操作支持撤销 | 删除确认、操作撤销 |
| **防错设计** | 预防错误发生 | 输入验证、操作确认 |
| **一致性** | 相同操作相同反馈 | 统一的交互模式 |
| **效率优先** | 减少操作步骤 | 快捷操作、批量处理 |

### 2.2 交互层级

| 层级 | 交互类型 | 示例 |
|-----|---------|------|
| L1 | 即时反馈 | 按钮悬停、点击效果 |
| L2 | 状态反馈 | 加载中、成功/失败提示 |
| L3 | 页面反馈 | 页面切换、弹窗 |
| L4 | 系统反馈 | 通知、邮件提醒 |

## 三、通用交互规范

### 3.1 按钮交互

#### 3.1.1 按钮状态

| 状态 | 视觉效果 | 交互说明 |
|------|---------|---------|
| **默认** | 正常颜色 | 可点击 |
| **悬停** | 颜色加深/变浅 | 鼠标移入，提示可点击 |
| **点击** | 颜色变化+轻微缩放 | 鼠标按下，即时反馈 |
| **加载** | 显示加载图标 | 操作处理中，禁用点击 |
| **禁用** | 灰色，无悬停效果 | 不可点击 |

#### 3.1.2 按钮类型

```
主要按钮:   [  确认创建  ]  ← 蓝色背景，白色文字，用于主要操作
次要按钮:   [  取消  ]      ← 白色背景，灰色边框，用于次要操作
危险按钮:   [  删除  ]      ← 红色背景，用于删除等危险操作
链接按钮:   查看详情        ← 文字形式，用于跳转
图标按钮:   [⚙️]           ← 图标形式，用于设置等操作
```

#### 3.1.3 按钮交互细节

```css
/* 按钮交互规范 */
.button {
  /* 默认状态 */
  background: #1890ff;
  color: white;
  border: none;
  border-radius: 4px;
  padding: 8px 16px;
  cursor: pointer;
  transition: all 0.3s ease;
  
  /* 悬停状态 */
  &:hover {
    background: #40a9ff;
    transform: translateY(-1px);
    box-shadow: 0 2px 8px rgba(24, 144, 255, 0.3);
  }
  
  /* 点击状态 */
  &:active {
    background: #096dd9;
    transform: translateY(0);
    box-shadow: none;
  }
  
  /* 禁用状态 */
  &:disabled {
    background: #f5f5f5;
    color: #bfbfbf;
    cursor: not-allowed;
    transform: none;
    box-shadow: none;
  }
  
  /* 加载状态 */
  &.loading {
    opacity: 0.7;
    cursor: wait;
  }
}
```

### 3.2 表单交互

#### 3.2.1 输入框交互

| 状态 | 视觉效果 | 说明 |
|------|---------|------|
| **默认** | 灰色边框 | 等待输入 |
| **聚焦** | 蓝色边框+阴影 | 当前输入框 |
| **填写** | 绿色边框 | 验证通过 |
| **错误** | 红色边框+错误提示 | 验证失败 |
| **禁用** | 灰色背景 | 不可编辑 |

#### 3.2.2 表单验证时机

| 验证类型 | 触发时机 | 反馈方式 |
|---------|---------|---------|
| **实时验证** | 输入过程中 | 即时显示验证结果 |
| **失焦验证** | 离开输入框时 | 显示验证结果 |
| **提交验证** | 点击提交按钮时 | 汇总显示所有错误 |

#### 3.2.3 表单交互示例

```

│  │ 1380000                     │   │  ← 错误状态：红色边框
│  └─────────────────────────────┘   │

├─────────────────────────────────────┤
│  邮箱                                │
│  ┌─────────────────────────────┐   │
│  │                             │   │  ← 默认状态：灰色边框
```

### 3.4 弹窗交互

#### 3.4.1 弹窗类型

| 类型 | 用途 | 关闭方式 |
|------|------|---------|
| **确认框** | 确认操作 | 点击确认/取消按钮 |
| **提示框** | 信息提示 | 点击确定按钮或关闭图标 |
| **表单弹窗** | 填写信息 | 提交或取消 |
| **详情弹窗** | 查看详情 | 点击关闭图标或蒙层 |

#### 3.4.2 弹窗交互规则

```
┌─────────────────────────────────────────────────┐
│  弹窗标题                              [×]      │
├─────────────────────────────────────────────────┤
│                                                 │
│              弹窗内容区域                        │
│                                                 │
├─────────────────────────────────────────────────┤
│              [取消]    [确认]                    │
└─────────────────────────────────────────────────┘
        ↑
        点击蒙层关闭（可配置）

交互规则:
1. 打开弹窗：淡入 + 轻微缩放动画 (200ms)
2. 关闭弹窗：淡出动画 (150ms)
3. 蒙层点击：可配置是否关闭
4. ESC键：关闭弹窗
5. 打开时：背景禁止滚动
```

## 七、动画规范

### 7.1 动画时长

| 动画类型 | 时长 | 缓动函数 |
|---------|------|---------|
| **微交互** | 150ms | ease-out |
| **组件动画** | 200ms | ease-in-out |
| **页面切换** | 300ms | ease-in-out |
| **弹窗动画** | 200ms | cubic-bezier(0.4, 0, 0.2, 1) |

### 7.2 动画效果

#### 7.2.1 淡入淡出

```css
/* 淡入 */
@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}

/* 淡出 */
@keyframes fadeOut {
  from { opacity: 1; }
  to { opacity: 0; }
}

/* 应用 */
.element {
  animation: fadeIn 200ms ease-in-out;
}
```

#### 7.2.2 滑动动画

```css
/* 从右滑入 */
@keyframes slideInRight {
  from {
    transform: translateX(100%);
    opacity: 0;
  }
  to {
    transform: translateX(0);
    opacity: 1;
  }
}

/* 应用 */
.page-enter {
  animation: slideInRight 300ms ease-in-out;
}
```

#### 7.2.3 缩放动画

```css
/* 弹窗缩放 */
@keyframes modalScale {
  from {
    transform: scale(0.8);
    opacity: 0;
  }
  to {
    transform: scale(1);
    opacity: 1;
  }
}

/* 应用 */
.modal {
  animation: modalScale 200ms cubic-bezier(0.4, 0, 0.2, 1);
}
```

## 九、无障碍交互

### 9.1 键盘无障碍

- 所有功能支持键盘操作
- 焦点顺序符合逻辑
- 提供焦点指示器

### 9.2 屏幕阅读器

- 图片提供alt文本
- 表单提供label关联
