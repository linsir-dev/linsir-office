## 三、Mockups设计规范

### 3.1 设计工具

- **主设计工具**: Figma
- **辅助工具**: Sketch / Adobe XD
- **标注工具**: Figma Dev Mode / Zeplin

### 3.2 画布设置

| 画布类型 | 宽度 | 高度 | 用途 |
|---------|------|------|------|
| 桌面端 | 1440px | Auto | 标准桌面页面 |
| 平板 | 768px | Auto | 平板适配 |
| 移动端 | 375px | Auto | 手机适配 |

### 3.3 命名规范

**页面命名**: `{模块}-{页面}-{状态}`

示例:
- `user-list-default`
- `user-list-filtered`
- `user-create-step1`
- `user-create-step2`
- `modal-delete-confirm`

**图层命名**: `{类型}-{元素}-{状态}`

示例:
- `btn-primary-default`
- `input-text-focus`
- `card-statistics-hover`

### 3.4 导出规范

| 类型 | 格式 | 分辨率 | 命名 |
|------|------|--------|------|
| 完整页面 | PNG | 2x | `{page-name}@2x.png` |
| 组件 | PNG | 2x | `{component-name}@2x.png` |
| 图标 | SVG | 矢量 | `{icon-name}.svg` |
| 切图 | PNG | 2x/3x | `{asset-name}@2x.png` |

## 七、设计交付规范

### 7.1 交付文件

| 文件类型 | 格式 | 用途 |
|---------|------|------|
| 设计源文件 | .fig | 设计稿源文件 |
| 标注文件 | Figma Dev Mode | 开发标注 |
| 切图资源 | PNG/SVG | 开发使用 |
| 设计规范 | PDF | 设计参考 |

### 7.2 切图规范

| 类型 | 格式 | 尺寸 |
|------|------|------|
| 图标 | SVG | 矢量 |
| 图片 | PNG @2x | 2倍图 |
| 背景 | PNG @2x | 2倍图 |

### 7.3 命名规范

**切图命名**: `{模块}_{元素}_{状态}`

示例:
- `login_logo_default.png`
- `btn_primary_hover.png`
- `icon_user_avatar.png`
