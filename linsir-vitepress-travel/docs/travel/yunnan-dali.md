## 🗓️ 行程安排

### Day 1-2: 大理古城

清晨的古城格外安静，石板路上的露水还未干。找一家临街的小店，点一杯咖啡，看来来往往的行人。

::: tip 推荐
- **最佳游览时间**：早上8点前或傍晚
- **必去地点**：洋人街、人民路、五华楼
- **特色体验**：逛早市、听民谣
:::

### Day 3-4: 洱海骑行

租一辆自行车，沿着洱海骑行，是最惬意的体验。

#### 推荐路线

```
大理古城 → 才村码头 → 喜洲古镇 → 双廊 → 小普陀 → 下关
```

全程约120公里，建议分两天完成。

### Day 5: 苍山索道

乘坐索道上苍山，俯瞰整个洱海。

## 💭 旅行感悟

> 在大理的这几天，时间仿佛变慢了。没有行程安排的压力，只有随心所欲的自在。早上睡到自然醒，午后在洱海边发呆，傍晚看日落，晚上听民谣。这大概就是旅行的意义吧。

大理教会了我慢下来的艺术。在这个快节奏的时代，能够找到一处让心灵栖息的地方，是多么珍贵。

---

## 💡 实用攻略

### 交通
- 从昆明坐高铁到大理，约2小时
- 古城内步行或租自行车即可
- 环洱海可以租电动车或包车

### 住宿
- 古城内：方便逛古城，但晚上可能吵
- 洱海边：风景好，适合发呆
- 才村码头：性价比高，离古城近

### 最佳季节
- **3-5月**：气候宜人，油菜花盛开
- **9-11月**：秋高气爽，天空最蓝
