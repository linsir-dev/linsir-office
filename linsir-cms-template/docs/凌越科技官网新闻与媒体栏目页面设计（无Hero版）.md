# 凌越科技官网新闻与媒体栏目页面设计（无Hero版）

核心规范：完全延续官网现有风格（深色科技底、蓝紫渐变主色、行业专属色调区分、卡片化布局、轻量动效），删除Hero区，优化模块衔接，聚焦新闻展示与品牌传递，适配桌面端/平板/移动端，可直接交付设计、前端落地；所有图片均贴合科技风与行业属性，确保与整体设计统一。

# 一、页面整体定位

- 栏目名称：新闻与媒体 / News & Media（页面顶部居中展示，替代Hero区核心标识）

- 核心作用：对外展示品牌动态、行业资讯、媒体报道、活动发布，传递凌越科技发展动态与行业影响力，提升品牌专业度与公信力，衔接官网整体导航逻辑。

- 风格延续：深色底（#111827）+ 蓝紫渐变（#6366f1→#a855f7）主色 + 三大行业色调（交通蓝青、医疗青绿、公共安全深紫）区分内容 + 卡片化设计 + 轻量交互动效，与合作生态、核心业务等板块风格统一；图片以暗调科技风为主，贴合整体色调，不突兀。

# 二、页面完整结构（从上到下，无Hero区，直接衔接导航栏）

导航栏 → 栏目标题 → 新闻分类Tab → 新闻列表区（核心，含封面图） → 分页区 → 底部CTA区 → 页脚（与官网统一）

# 三、各模块详细设计（可直接复制给设计/前端，含文案、样式、适配、图片规范）

## 1. 栏目标题（承接导航栏，页面首屏顶部，替代Hero区标识）

定位：快速告知用户当前栏目，简洁大气，贴合科技风，与后续分类Tab自然衔接。

# 新闻与媒体

News & Media

洞察行业前沿，传递凌越科技动态 · 聚焦智慧交通、医疗AI、公共安全领域

### 视觉适配

- 标题无额外背景，直接衔接导航栏，底部浅灰色细边框分隔，避免与分类Tab混淆；

- 字体：标题无衬线粗体，英文副标题略小，描述文本轻量，整体居中对齐；

- 响应式：移动端标题字号缩小至1.5rem，描述文本换行展示，保持居中。

## 2. 新闻分类Tab（栏目标题下方，核心筛选模块）

定位：方便用户快速筛选所需新闻类型，分类清晰，交互便捷，贴合官网交互逻辑。

### 样式规范

- 选中状态：蓝紫渐变下划线（与官网CTA渐变一致）+ 白色文字（加粗）；

- 未选中状态：浅灰色文字（无下划线），hover时文字透明度提升至0.9；

- 响应式：桌面端固定间距，平板端间距缩小至24px，移动端横向滚动（隐藏滚动条），确保所有分类可查看。

## 3. 新闻列表区（页面核心，新闻展示模块）

定位：核心展示区域，卡片化布局，突出新闻关键信息、封面图，兼顾美观与可读性，延续官网合作生态板块卡片风格；图片为核心视觉元素之一，贴合新闻内容与行业调性。

### 布局规范

- 桌面端：3列网格布局，卡片间距24px，整体居中，左右留白均匀；

- 平板端：2列网格布局，卡片间距20px；

- 移动端：1列布局，卡片宽度100%，上下间距20px。

### 图片规范（核心补充，贴合整体风格）

- 图片类型：新闻封面图（单条新闻配套），优先选用与新闻内容强相关的实景图或行业抽象科技图；

- 尺寸比例：严格遵循16:9，适配卡片布局，避免拉伸、变形，确保桌面端/移动端显示协调；

- 色调要求：整体偏暗调，呼应页面深色底色（#111827），可叠加轻微深色遮罩（透明度20%-30%），保证卡片内白色/浅灰色文字清晰可读；

- 内容要求：
        

    - 公司动态：优先用合作签约图、公司活动图，无实景图用蓝紫渐变科技线条图替代；

    - 行业资讯：优先用交通/医疗/公共安全场景图（如智能公交、医疗影像、安防大屏），无实景图用对应行业色调抽象数据流图替代；

    - 媒体报道：优先用专访图、媒体拍摄图，无实景图用深紫色调AI算法抽象图替代；

- 样式要求：卡片内图片圆角8px，无多余边框，溢出部分隐藏，与卡片整体风格融合。

### 卡片样式与标签色调规范（核心）

- 卡片基础样式：深色半透明底色（rgba(255,255,255,0.05)），8px圆角，轻微阴影（0 2px 8px rgba(0,0,0,0.2)）；

- 交互动效：hover时卡片上浮5px、轻微放大（1.02倍）、边框高亮（蓝紫渐变细边框），阅读更多箭头轻微右移，图片同步轻微放大（1.03倍），贴合官网其他卡片交互逻辑；

- 标签色调（区分新闻类型，联动三大行业）：
        

    - 公司动态：蓝紫渐变（#6366f1→#a855f7），贴合品牌主色；

    - 行业资讯：交通蓝青渐变（#3b82f6→#06b6d4），联动智慧交通业务；

    - 媒体报道：公共安全深紫渐变（#8b5cf6→#a78bfa），联动智能安防业务。

## 4. 分页区（新闻列表下方，衔接列表与CTA区）

定位：方便用户查看更多新闻，交互简洁，贴合官网整体交互风格，不冗余。

- 选中页码：蓝紫渐变背景、白色文字、无边框；

# 四、配套：新闻详情页设计（衔接列表页，完整闭环）

定位：展示单条新闻完整内容，提升阅读体验，引导用户浏览更多相关新闻，延续整体风格；图片规范与列表页一致，兼顾可读性与视觉统一性。

## 详情页结构（从上到下）

- 返回列表按钮（左上角，浅灰色文字+箭头，hover时变色）；

- 新闻标签（与列表页一致，对应分类色调）；

- 新闻标题（居中，白色粗体，字号1.8rem，margin-bottom: 16px）；

- 发布日期（居中，浅灰色文字，margin-bottom: 24px）；

- 新闻封面图（居中，宽度100%，最大宽度800px，圆角8px，margin-bottom: 24px；图片规范与列表页一致，可选用高清版）；

- 正文内容（居中，最大宽度800px，白色文字85%透明度，行高1.6倍，段落间距24px）；

- 正文插图（若有）：居中展示，宽度100%，最大宽度700px，圆角8px，margin: 24px 0；色调、样式与封面图统一，贴合新闻内容；

- 页脚（与官网统一）。

### 详情页样式规范

- 正文小标题：蓝紫渐变文字，加粗，字号1.2rem，margin: 32px 0 16px；

- 正文图片：居中展示，带轻微阴影（0 2px 8px rgba(0,0,0,0.3)），无多余边框，避免亮度过高；

- 响应式：移动端标题字号缩小至1.4rem，正文字号缩小至0.9rem，相关新闻改为1列布局，正文插图最大宽度改为90%屏幕宽度。
